# Glimpse 桌面客户端设计说明

对象：0.0.2 的 Windows 客户端（主控面板、托盘、窗口内读数、首次引导、异常态）。
交付物：可运行的 HTML 设计稿 + 截图 + 本说明。**未改任何 C# 代码**，落地映射见第 9 节。

## 1. 方向

**Stage Black（暗场后台）**：像灯控台一样，一眼确认「信号还活着」，其余退到黑里。

1. 预览窗本身是纯黑加一帧画面，客户端跟它同一档黑，演出中切回面板不跳色、不晃眼。
2. 使用场合是暗场侧台，用户长时间盯屏，只有数字和状态灯该发亮。
3. 这个产品唯一需要「看懂」的是两块屏的拓扑和几个数字，拓扑图正好当主视觉，不需要再编装饰。

调性五刻度：能量**安静**（强调色面积 ≤ 8%）、完成度**精致**（1px 对齐、无阴影）、
密度**密**（一屏看完）、分量**重**（黑底 + 等宽数字 + 硬边）、严肃度**庄重**（无插画、无跳动效）。

## 2. 界面清单

| 文件 | 内容 |

## 3. 指标：五项，一套名字

只保留 `StatsReporter` 里真实存在的测量量。面板、报告、日志用同一套名字，括号里是日志字段：

| 界面名称 | 日志字段 | 定义 |
| --- | --- | --- |
| 捕获帧率 | `cap` | 本秒 `FrameStats.Captured` |
| 呈现帧率 | `show` | 本秒 `FrameStats.Presented` |
| 回调年龄 p95 | `age` | 采集时刻 → 回调时刻（`WgcFrameSource` 收到的时刻） |
| 端到端 p95 | `present` | 采集时刻 → 呈现时刻（`Present` 返回前） |
| 丢帧 | `drop` | 本秒 `FrameStats.Dropped` |

约束：同一次采集里 **回调年龄 ≤ 端到端**（面板上写了这句，测试结果表里也按此判定）。
不再出现「帧年龄 / 捕获回调 / 呈现延迟」这类别名或第三个延迟分布——没有对应的测量量。

报告表沿用这五个名字，另加 CPU 与「帧率目标 58 fps」两行；日志保留 `cap= show= drop= age(...) present(...)` 原格式。

## 4. 主控面板结构

窗口 1440×900（最小 1180×720），三层：

- **标题栏 44px**：字标 + 版本 + 系统窗控。
- **图标轨 56px**：监看 / 测试 / 诊断 / 日志，各带 11px 文字标签（"测试"和"诊断"的图形太接近，不能只靠图形）；底部收起与帮助。窄窗口收到 46px，只留图形。
- **主区**：链路通不通（运行条 + 拓扑）→ 现在连的是哪两块屏（源 / 输出）→ 要不要测一次（基准测试摘要）。
- **右栏 312px（≥1280）**：画面缩略 + 五项读数 + 60 秒延迟折线 + 设备环境。**<1280 时收成抽屉**，运行条上出现「读数」入口。
- **状态栏 26px**：日志路径 + 热键 + 版本。

### 4.1 显示器选择与控制

- 选屏用**屏幕卡**：显示 Windows 显示设置里的编号（显示 1 / 显示 2）、宽高比缩略框、刷新率、分辨率、适配器。
  **未选中的卡压成单行**（缩略框 + 名称 + 分辨率），选中的卡才展开第二行，密度降下来而身份不丢。
- 两块屏不能选同一块：在源里选中当前输出屏时自动交换。
- 拓扑按物理比例画两块屏，链路带上有**常驻箭头**（暂停或无帧时方向仍然可读）和流动帧点；
  断链时点停在半路、箭头变红。
- 控制项：投屏源（光标、自身窗口、HDR、捕获区域、隐身状态）与
  预览输出（尺寸 25/50/75/100%、贴边位置、始终最前、窗口内读数、帧延迟上限）。
  **点击穿透放在运行条上**——它是演出中唯一会被临时切换的开关。
- 跨适配器输出用黄色药丸标在「预览输出」标题栏（+8 ms），不弹窗、不拦操作。

### 4.2 软件测试（基准测试）

**单一入口**：监看页只给「上次摘要 + 开始测试 + 报告」，全部配置在测试视图，两处不再各配一套。

- 配置：单次时长（15 秒 / 60 秒 / 5 分）、采样窗口、阈值（fps、p95）、重复次数（取中位数）、
  测试时暂停预览、完成后自动导出、与基线表对比。
- 结果：按五项指标 + CPU 对照 0.0.2 基线，未达标项写清瓶颈（「瓶颈在 WGC 出帧」）。
- 运行中：进度 + 捕获 fps / 端到端 p95 / 端到端 max / 丢帧 / CPU，与面板同一套名字。
- 报告：Markdown 导出、复制表格、打开日志目录，显示真实落盘路径。

### 4.3 状态与异常

| 状态 | 触发 | 表现 | 主操作 |
| --- | --- | --- | --- |
| run | 正常 | 绿点、拓扑实线、五项读数 | — |
| **switch** | 换源，重建 WGC 会话 | 琥珀运行条、源屏虚线「切换中」、链路改「正在重建 WGC 会话」、**预览窗保留最后一帧 + 半透明角标**，不出现黑场 | 等待（可取消） |
| **switchfail** | 新会话建立失败 | 黄色横幅「已回退到原来的屏」，画面与读数继续 | 重试切换 / 查看日志 |
| drm | 受保护内容或独占全屏 | 红色横幅、源屏红斜纹「无帧」、链路停止 | **查看排查步骤**（主）/ 重试捕获（次） |
| lost | 源显示器热插拔 | 黄色横幅、源屏虚线「已断开」、卡片挂「已断开」 | 重新枚举 / 选择其他屏 |
| bench | 基准测试进行中 | 进度 + 实时指标 | 停止测试 |

异常态把拓扑压到一半高度，把横幅和恢复动作顶到最前：出问题时注意力只够看一处。
DRM 重试通常无效，所以主按钮是排查步骤；断屏**不静默回退**到另一块屏。

### 4.4 生命周期

- **关闭窗口 / 最小化 = 收进托盘**，捕获与呈现不停，舞台画面不中断。第一次关闭时问一次并记住选择。
- **托盘「退出」= 真正退出**，正在监看时二次确认（退出会让舞台立刻失去预览）。
- **单实例**：第二次启动激活已有面板并置前，不弹 MessageBox，也不新起进程。
- 开机自启：登录后静默进托盘，不开面板、不抢焦点。

### 4.5 持久化

`AppSettings` 里显示器相关的键改用 `GetMonitorInfoW` 的 `szDevice`（如 `\\.\DISPLAY2`）作主键，
`Index` 只在设备名找不到时兜底；两者都失效时按当前枚举重新推导并提示一次。
面板显示 Windows 编号，避免用户对着系统显示设置选屏时选错。

## 5. 面板以外的四个面

- **托盘**：唯一入口。菜单项与面板开关共用状态；图标四态只换颜色不换形状
  （白 = 正常、琥珀 = 穿透中、红 = 无画面、灰 = 暂停），不带帧率。
- **窗口内读数**：独立子窗口，只两个数，超阈值变琥珀，3 秒无帧才变红并写秒数。
- **首次引导**：三步（确认两块屏 → 确认管线 → 试运行 10 秒），跨适配器用黄色「!」。
- **收起态**：520×52 细条，只留状态灯、链路、两个数字和穿透开关。

## 6. 视觉规范

- 色板：底 `#08090B`、面板 `#101215`、线 `#21252B`、主文字 `#E8EBF0`、
  琥珀 `#F2A93B`、正常 `#45D6A0`、警告 `#E8B23C`、错误 `#EF5B5B`。
  强调色只用于选中、主动作、当前读数；状态色不可当强调色用。
- 字体：正文 `Segoe UI Variable Text` → 回退 `Segoe UI`（Win10）；中文回退 `Microsoft YaHei UI`；
  数字与路径 `Cascadia Mono` → 回退 `Consolas`。字体链在 CSS 变量里写全，不假设机器装了哪个。
- 控件语法：2px 圆角、1px 描边、无阴影、按下位移 1px；所有按钮与片段 `white-space:nowrap`，
  行内只允许收缩父容器，不允许压扁按钮文字。
- 图标：inline SVG，1.2–1.5px 描边、方端点；落地转 `GraphicsPath` 自绘或按 16/20/24/32 出位图。
- 动效三处：帧点流动、状态切换 120–160ms、测试进度。无入场动画。

## 7. 布局与窄屏

| 宽度 | 规则 |
| --- | --- |
| ≥ 1440 | 双列控制 + 常驻右栏，一屏放满 |
| 1280–1439 | 双列，右栏在 |
| 1180–1279 | 单列不换，右栏改抽屉（宽 312，内部滚动，标题栏有「收起」），图标轨 46px 只留图形，拓扑压缩、底部链路元数据隐藏 |

最小窗口 1180×720。更窄不做——低于这个宽度，两块屏的拓扑和数字已经无法同时成立。
DPR/DPI 另算：**96% / 125% / 150% 三档需要在落地前用真实窗口验一遍**，1px 线在 150% 的 GDI+ 上会发虚，
必要时按物理像素对齐（第 9 节）。设计稿本身是 96 DPI 的 1440×900。

## 8. 交互与状态

- 改了就生效，面板里没有「保存」按钮；只有测试配置落盘，标题栏写明「配置随设置保存 · 下次启动沿用」。
- 主操作每块一个：运行条是暂停/开始，基准测试块是开始测试。
- 处理中保持按钮尺寸、防重复提交；测试可后台跑，面板可继续操作。
- 失败留在原处：原因和恢复动作就在横幅里，不弹角落提示。

## 9. 落地映射（WinForms + D3D11）

| 设计决定 | 实现要点 |
| --- | --- |
| 预览窗只有画面 | 维持 `WS_EX_NOREDIRECTIONBITMAP`；读数走独立分层子窗口，不进交换链 |
| 面板是普通 Form | 自绘边框/开关/屏幕卡，不引入 XAML 运行时 |
| 面板不参与渲染循环 | 读数 1Hz 批量刷新；最小化或收起进托盘时停定时器 |
| 关闭 = 收托盘 | `FormClosing` 拦一次写设置；托盘「退出」置真退出标志；单实例 `Mutex` 后 `SetForegroundWindow` |
| DPI | 面板 PerMonitorV2 逻辑坐标；预览窗仍用物理像素；1px 线按 `Math.Round(1 * dpi/96)` 对齐 |
| 托盘 | `NotifyIcon` + 自绘 16/20/24/32 图标；菜单自绘或换色的 `ContextMenuStrip` |
| 屏幕卡 / 拓扑 | `IMonitorEnumerator` 的 `MonitorDescriptor` 扩展 `DeviceName`（`szDevice`）；按 Width/Height 算比例 |
| 图标 | 设计稿是 inline SVG，落地转 `GraphicsPath` 或位图，不引图标字体 |
| 设置 | 沿用 `AppSettings`；新增 `HideCursor`、`HdrMode`、`TestDuration`、`TestSampleWindow`、`FpsThreshold`、`LatencyThreshold`、`TestRepeat`、`AutoExportReport`、`CloseToTray`、源/输出的 `DeviceName` |

## 10. 分期（避免 M2 膨胀）

| 期 | 内容 |
| --- | --- |
| **M2** | 托盘与关闭/最小化语义、单实例、监看页（拓扑 + 选屏 + 输出控制）、点击穿透与热键、设置持久化（`szDevice`）、切换中/切换失败状态 |
| **M2.5** | 窗口内读数、收起细条、首次引导（三步，可跳过）、诊断视图（设备 + 日志尾 + 诊断包） |
| **M3** | 基准测试与报告导出、热插拔恢复、设备丢失重建、HDR、DPR 校验、1 小时长稳 |

设计稿里的「上报表格 / 导出 Markdown」属于 M3；M2 不碰。

## 11. 未做与假设

- 只做设计稿，没接后端：截图里的数字取这台机器 0.0.2 的实测区间（42 fps、age p95 15 ms、present p95 18 ms、丢帧 0），
  「上次结果」的时间是示意。
- 只做暗色，没有浅色版——预览窗是黑的，浅色面板会破坏暗适应。
- 没做多套预设、预览窗透明度、拖动拓扑改布局：当前场景只有一个源 + 一个输出。
